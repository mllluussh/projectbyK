Milana's personal website - HTML, CSS and JavaScript

HOW TO RUN
1. Keep index.html, style.css, script.js and the images folder together.
2. Open the folder in VS Code and use Live Server (or just open index.html in a browser).

JAVASCRIPT FUNCTIONS (script.js)
1. toggleMenu()   - shows / hides the menu on phones (burger button)
2. toggleTheme()  - switches light and dark theme, remembers the choice
3. validateForm() - checks name, email and message in the "Write to me" form
                    and shows error messages or a success message
4. openModal() / closeModal() - opens a photo from "My life" in a big window
